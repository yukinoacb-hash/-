# 苍穹外卖 — 第 1 课：项目搭建 + 三层架构跑通

## 学到了什么

今天从零搭建了 Spring Boot 项目，跑通了第一个接口 /employee，掌握了企业级三层架构的完整流程。

## 核心概念

### 三层架构
Controller 接收请求调 Service，Service 业务逻辑调 Mapper，Mapper 操作数据库。

### 关键注解
- @RestController 标记控制器返回 JSON
- @RequestMapping 统一路径前缀
- @GetMapping 处理 GET 请求
- @Autowired 自动注入 Bean
- @Service 标记 Service 实现类
- @Mapper 标记 Mapper 接口

### Result 统一返回格式
Result.success(data) 和 Result.error(msg)

### 为什么要接口加实现类
可替换、可测试、Spring 事务管理需要

## 踩过的坑

- 循环依赖：ServiceImpl 注入了自己，应该注入 Mapper
- 找不到 Bean：Mapper 没被扫描到，加 @MapperScan
- Circular view path：用了 @Controller 而不是 @RestController
- Spring Boot 4 和 MyBatis 不兼容：降级到 3.2.5
