## 🕳️ 三、已踩过的坑总表（复习用）

| # | 坑 | 现象 | 正解 | 课 |
|---|---|---|---|---|
| 1 | 循环依赖 | 启动报 bean 循环（ServiceImpl 里注入了自己） | 实现类里只注入 Mapper，别注入自己的接口 | 1 |
| 2 | 找不到 Bean | `required a bean of type 'EmployeeMapper'` | 启动类加 `@MapperScan` | 1 |
| 3 | Circular view path | 访问接口 500 | `@Controller` → `@RestController` | 1 |
| 4 | Spring Boot 4 与 MyBatis 不兼容 | 启动/编译失败 | 父版本降到 **3.2.5** | 1 |
| 5 | **改了代码没重新编译** | 405 / 结果没变化 | 🔴 停止 → ▶ 重启（跑的是 `target/classes`） | 3 |
| 6 | 服务没启动 | `Connection refused` | 先跑 SkyTakeoutApplication | 3 |
| 7 | username 唯一索引冲突 | 500 `Duplicate entry 'xx' for key` | 换个用户名 / 先删再插（**lisi 又踩了一次**） | 3、8 |
| 8 | `DELETE * FROM` | SQL 语法错误 | `DELETE FROM` —— `*` 只属于 `SELECT` | 4 |
| 9 | 全字段覆盖式 UPDATE | 数据被写成 null | 改动态 SQL（`<set>` + `<if>`） | 5、6 |
| 10 | XML 里列名写成属性名 | `Unknown column 'idNumber'` | SQL 里写下划线 `id_number` | 6 |
| 11 | 时间类型和 `''` 比较 | `IllegalArgumentException` | 时间字段只判 `!= null`，**不要**比空串 | 6 |
| 12 | pom 依赖名写错 | `spring-boot-starter-webmvc` 报缺版本 | 是 `spring-boot-starter-web` | 1 |
| 13 | **登录漏写 `!`** | 正确密码登不上、错密码反而进得去 😱 | `if (!md5.equals(...)) return null;` | 8 |
| 14 | `username == null` 检查打不中要害 | 以为防了 NPE | 真正会 NPE 的是 `password.getBytes()` | 8 |
| 15 | 方法声明了返回值，分支没 return | 编译报"缺少返回语句" | 所有路径都要有返回值（提前撤退 + 兜底 return） | 8 |
| 16 | Javadoc 开头少写一个星（写成 `/*`） | `@param` 报“无法解析符号” | 文档注释必须 `/**` 开头 | 9 |
| 17 | 改了接口 `login` 返回类型，Controller 没同步改 | Controller 编译标红 | 接口 / 实现 / 调用方三处类型一起改 | 9 |
| 18 | **自动导入导错包**：`java.net.http.HttpRequest` / `HttpResponse` | `getHeader`、`setStatus` 双双标红，两个 `@Override` 也红 | 值应该是 `jakarta.servlet.http.HttpServletRequest` / `HttpServletResponse`（认准 `jakarta.servlet.http` 包） | 10 |
| 19 | `list` 的 XML 里写成 `SELECT COUNT(*)` | **不报错**，但 records 全是 null 空壳 | 查列表用 `SELECT *`，查总数才用 `SELECT COUNT(*)` | 11 |
| 20 | `IMIT #{offset}, #{pageSize}` | SQL 语法错误 | `LIMIT` 有两个 L | 11 |
| 21 | 分页 DTO 字段没写默认值 | 不传参 → `(page-1)*pageSize` 对 null 做算术 → NPE → 500 | `page=1` / `pageSize=10`，后端自己兜底 | 11 |
| 22 | **`@PutMapping` 写成了 PUT** | 前端按黑马发 POST → **405 Method Not Allowed** | 黑马启停接口用 POST；前后端 HTTP 方法必须一致 | 11 |

### 🚑 排错口诀

| 现象 | 先怀疑什么 |
|---|---|
| **405** | 路径对，但**方法**不对（GET 还是 POST？） |
| **404** | 路径根本不存在（拼错 / 少写） |
| **415** | 忘写 `Content-Type: application/json` |
| **500** | 去 IDEA 控制台翻最下面的 **`Caused by:`** |
| **Connection refused** | 服务没启动 |
| **改了没效果** | 没重新编译 / 没重启 |

### 包结构

```
com.sky.skytakeout
├── SkyTakeoutApplication        @SpringBootApplication + @MapperScan
├── common/Result                统一返回结果（code/msg/data）
├── common/BaseContext           ThreadLocal 存"当前登录人 id"
├── common/PageResult<T>         分页返回（total + records）
├── config/WebMvcConfiguration   注册拦截器 + 放行 /employee/login
├── controller/EmployeeController 5 个 CRUD + 1 个登录
├── controller/CategoryController 新增 + 分页 + 启停（还剩 2 个接口）
├── dto/EmployeeLoginDTO         登录入参（username/password）
├── dto/CategoryDTO              新增分类入参（type/name/sort）
├── dto/CategoryPageQueryDTO     分页查询入参（page/pageSize/name/type，带默认值）
├── entity/Employee              对应 employee 表
├── entity/Category              对应 category 表（9 个字段）
├── interceptor/LoginCheckInterceptor  JWT 校验 + BaseContext 存 empId
├── mapper/EmployeeMapper        @Select/@Insert/@Delete + XML 里的 update
├── mapper/CategoryMapper        @Insert/@Select/@Delete + XML 里的 list/count（update 待补）
├── properties/JwtProperties     @ConfigurationProperties 读 sky.jwt.*
├── service/                     接口 + 实现
├── util/JwtUtil                 发牌(createJWT) / 验牌(parseJWT)，static 工具类
└── vo/EmployeeLoginVO           登录出参（只给前端 id / userName / name / token）
```
