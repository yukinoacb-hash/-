## 一、JDBC — Java 连接数据库

### JDBC 是什么
Java 官方定义的数据库操作接口（`java.sql` 包），MySQL 厂商提供实现（驱动 jar 包）。

### 6 步流程
```
① 获取连接     → DriverManager.getConnection(url, user, pwd)
② 创建语句     → conn.prepareStatement(sql)
③ 设置参数     → pstmt.setInt(1, 值)   ← 索引从 1 开始
④ 执行 SQL     → pstmt.executeQuery()  查
               → pstmt.executeUpdate() 增删改
⑤ 处理结果     → rs.next() / rs.getInt("列名")
⑥ 关闭资源     → try-with-resources 自动关闭
```

### PreparedStatement（防 SQL 注入）
```java
// ✅ 安全：? 占位符，值和 SQL 分离
String sql = "SELECT * FROM student WHERE id = ?";
PreparedStatement pstmt = conn.prepareStatement(sql);
pstmt.setInt(1, 1);
```

### 事务
```java
conn.setAutoCommit(false);    // 关自动提交
try { conn.commit(); }        // 成功 → 提交
catch { conn.rollback(); }    // 失败 → 回滚
```

### 连接池（HikariCP）
- 每次创建连接很慢 → 提前创建一批放池里，用的时候借，用完归还
- `close()` 不是关闭，是归还到连接池

## 二、MyBatis — 持久层框架

### MyBatis 解决了什么
| JDBC | MyBatis |
|------|---------|
| 手动管理连接 | 自动管理 |
| 手动设参数 | `#{xxx}` 自动映射 |
| 手动封装 ResultSet | 自动转成 Java 对象 |
| 大量模板代码 | 只需写 SQL 和接口 |

### 核心三件套
```
① Mapper 接口（方法签名）  →  Student findById(int id);
② Mapper XML（SQL）       →  <select id="findById" ...>
③ 使用（调用）             →  mapper.findById(1)
```

### XML 的 4 个标签
```xml
<select id="方法名" resultType="返回类型"> SELECT ... </select>
<insert id="方法名"> INSERT INTO ... VALUES(#{属性}) </insert>
<update id="方法名"> UPDATE ... SET ... WHERE ... </update>
<delete id="方法名"> DELETE FROM ... WHERE ... </delete>
```

### #{ } vs ${ }
- `#{}` → 安全的，PreparedStatement 方式 ✅ 99% 用这个
- `${}` → 拼接字符串，有 SQL 注入风险 ❌ 只有表名/列名才用

### MyBatisX 插件
- 装好后，接口和 XML 之间可以跳转
- Alt+Enter 自动生成 SQL 标签骨架

## 三、Spring 核心

### IoC（控制反转）
- 传统：你自己 `new` 对象 → 你控制
- Spring：你不用 `new`，Spring 帮你创建和管理 → 控制反转

### DI（依赖注入）
- Spring 把你需要的对象直接"注入"给你
- `@Autowired` = "Spring，把这个对象给我"

### 容器和 Bean
- **Bean** = 被 Spring 管理的对象
- **容器** = 存放 Bean 的大箱子
- Spring 启动时扫描注解，创建 Bean 放进容器

### 三层架构
```
Controller（接收请求）  →  @RestController
      ↓
Service（业务逻辑）     →  @Service
      ↓
Mapper（操作数据库）    →  @Mapper
```

### 各层注解
| 注解 | 层 | 作用 |
|------|----|------|
| `@RestController` | 表现层 | 接收 HTTP 请求，返回 JSON |
| `@Service` | 业务层 | 写业务逻辑 |
| `@Mapper` | 数据层 | MyBatis 的 Mapper |
| `@Autowired` | 任意 | Spring 自动注入对象 |

### @SpringBootApplication
做了 3 件事：
1. `@ComponentScan` — 扫描包，找 Bean
2. `@EnableAutoConfiguration` — 自动配置（Tomcat、MyBatis...）
3. `@SpringBootConfiguration` — 标记这是配置类

### @Transactional
- 加在方法上，Spring 自动管事务
- 方法成功 → commit，方法报错 → rollback
- 底层原理就是 JDBC 的 `setAutoCommit(false)` + `commit/rollback`

## 四、Spring Boot REST API

### HTTP 4 种请求
| 操作 | HTTP 方式 | 注解 | 数据来源 |
|------|----------|------|---------|
| 查 | GET | `@GetMapping` | URL 路径或参数 |
| 增 | POST | `@PostMapping` | 请求体（JSON） |
| 改 | PUT | `@PutMapping` | URL 路径 + 请求体 |
| 删 | DELETE | `@DeleteMapping` | URL 路径 |

### 从请求里拿数据的 3 种方式
```java
@PathVariable   // 从 URL 路径拿：/students/{id}       → id=1
@RequestParam   // 从 URL 问号后拿：/search?name=张    → name="张"
@RequestBody    // 从请求体拿 JSON：{"name":"张"}      → Student 对象
```

### REST API 设计规范
```
GET    /students         查全部
GET    /students/1       查单个
POST   /students         新增
PUT    /students/1       修改
DELETE /students/1       删除
GET    /students/search  搜索
```
