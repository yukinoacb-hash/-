# 力扣热题 100 · 第 1 题：两数之和（Two Sum）

> 难度：简单 ｜ 标签：数组、哈希表 ｜ 类型：哈希表经典入门

## 📖 题目
给定整数数组 `nums` 和目标值 `target`，找出和为 `target` 的两个数，返回它们的**下标**。保证恰好一个答案，同一元素不能用两次。

```
nums = [2, 7, 11, 15]   target = 9
答案：[0, 1]   （2 + 7 = 9）
```

## 🧠 关键要点

### 思路推导
1. **暴力法**：双重循环枚举每一对，时间 O(n²)。
2. **换问法（核心）**：不问"哪两个数相加"，改问"对当前数 `nums[i]`，我还差 `target - nums[i]`，这个差之前见过吗？"
3. 用一个 **HashMap 当"本子"** 记录「见过的数 → 下标」，查搭档只要 O(1)。
4. **一次遍历**：先查搭档在不在，没有就把自己记进本子。

### 为什么用哈希表
- 需要频繁做"某个值出现过吗 / 在哪"的查询
- HashMap 查询平均 O(1)，用 O(n) 空间换取 O(n) 时间

## 📝 代码示例

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // 本子：key = 数字，value = 它的下标
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];   // 我需要的搭档

            // 先查：搭档之前出现过吗？
            if (map.containsKey(need)) {
                return new int[]{ map.get(need), i };
            }

            // 没找到，才把自己记进本子
            map.put(nums[i], i);
        }

        return new int[]{};   // 题目保证有解
    }
}
```

### 暴力法（对照用）
```java
for (int i = 0; i < nums.length; i++)
    for (int j = i + 1; j < nums.length; j++)
        if (nums[i] + nums[j] == target) return new int[]{i, j};
```

## 📊 复杂度分析

| 维度 | 暴力法 | 哈希表法 |
|------|--------|----------|
| 时间 | O(n²) | O(n) |
| 空间 | O(1) | O(n) |

## ⚠️ 注意事项 / 常见坑

- **先查再放，顺序不能反！** 先放再查会在 `target = 2 * nums[i]` 时查到自己，同一个元素用了两次。
- **重复元素无需特殊处理**：`[3, 3], target = 6` → 第 0 个 3 进表，第 1 个 3 查命中，返回 `[0, 1]`。
- 返回的是**下标**不是数值。
- 返回数组用 `new int[]{a, b}`，别单独一行写成 `{a, b}`（编译不过）。
